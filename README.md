# 焼き付け字幕リーダー Android v0.3.14

ブラウザで再生中のYouTube画面をMediaProjectionで取得し、ML Kit日本語OCRとAndroid標準TTSだけで、映像へ焼き付けられた字幕を読み上げます。動画・画像・認識結果は端末外へ送りません。

## v0.3.14の主な変更

- 発話状態を「待機中・発話中・完了」に分け、TTSが完了した行だけを既読として記録
- 分割して認識した行が後で複数行字幕へ結合されても、既読行を除いた新しい行だけを発話
- 待機中の部分字幕が完全字幕へ置き換わる場合、待機行を完全字幕へ引き継いで欠落を抑制
- 中断・TTSエラー・待ち行列からの破棄では既読にせず、表示中なら再検出可能に変更
- 連続再生モードを実際のFIFO動作へ修正し、待機字幕を追従バランス方式で破棄していた問題を解消
- 実診断ログから固定したイベント抜粋を、旧版と新版へ同じ順序で通す再現評価を追加

詳しい検証範囲と残課題は `RELEASE-v0.3.14.md` を参照してください。

## v0.3.3の主な変更

- ML Kitが別ブロックへ分割した日本語2〜3行を、行間・文字高・横方向の重なりから1字幕へ統合
- 結合済み字幕の各行を別候補として競合させず、上段が2本の追跡上限から漏れる経路を修正
- 認識済みの3行から先頭／末尾の1行が一時的に抜けても、既知の全文を優先し再読を抑制
- 新しい行の追加時は安定待ちをやり直し、途中表示を急いで読まない
- スリープ設定を「画面共有中の自動消灯を防ぐ」に改称し、ロックボタン非対応を明記
- システムによる共有終了時の説明を停止後も保持

## v0.3.2で追加した機能

- 画面内の字幕帯を最大2本まで別々の追跡IDで同時追跡
- 上部の複数行字幕と下部の短い会話字幕を、独立したSubtitle Stabilizerで確定
- 同じOCRフレームで複数字幕が確定した場合は、画面の上から下の順で1回のTTSへ統合
- 複数行ブロックと、その中に含まれる各OCR行を同じ字幕として重複排除
- 字幕帯が一時的に消えた場合は、他方の字幕追跡を維持したまま個別に待機・失効
- 画面共有中の自動消灯を防ぐ設定を追加（既定でオン、停止時は必ず解除）

## v0.3.1までの主な機能

- 縦位置だけでなく、基準線・文字高・左／中央／右の画面アンカーを時間追跡
- カメラ移動やズームに伴って動く物体文字を、字幕の文章更新として数えない
- 同じ画面アンカーで文章が2フレーム継続して置き換わった場合に字幕帯をロック
- 広範囲が急変する場面転換を検出し、前後の物体文字を同じ字幕帯として結び付けない
- 字幕位置の決め打ちはせず、上部・中央・下部字幕へ対応
- 画面アンカーが安定しない動画内文字は字幕候補として確定しない
- 短い字幕は同じアンカーで文章が変化したことを確認してから読み上げ
- OCR揺れを字幕変更として数えない文字長別の類似度判定
- プレーヤー下端の字幕も除外せず、位置は弱い補助情報としてのみ利用
- 「20 BAR」など短い英数字の製品表記・仕様表記を字幕候補として抑制
- 縦画面のブラウザではOCR対象を上部の動画プレーヤー周辺へ限定
- アドレスバー、動画タイトル、コメント欄に相当する上下端のOCR行を自動候補から除外
- ML Kitの行座標を利用した字幕帯の自動検出（既定）
- 字幕位置・中央寄せ・文字サイズ・時間変化を組み合わせ、ロゴやブラウザUIを抑制
- 手動ROIは自動検出が合わない動画の補助機能として維持
- OCRが一時的に空になっても直前字幕を忘れず、類似字幕を60秒間重複除去
- 「追従バランス」では現在の文を最後まで読み、待機中は最新字幕1件だけを保持
- 待ち時間に応じて読み上げ速度を最大45%自動加速
- 通知アクセスを許可した場合、対応ブラウザのMediaSessionを停止・再開する「完全読み上げ」

## 対応範囲

- Android 8.0以上（Galaxy S25 / Android 16を主対象）
- Chrome、Samsung Internetなどで表示する日本語横書き字幕
- 自動字幕帯 / 手動字幕領域
- 自動検出時は最大2本の字幕帯を同時追跡
- 追従バランス / 最新字幕優先 / 完全読み上げ
- 約2〜3fpsのローカルOCR

## 推奨の使い方

1. 検出範囲を「自動検出（推奨）」にします。
2. 読み上げを「追従バランス」にします。
3. 「画面共有を開始」を押し、Androidの確認画面で許可します。
4. ブラウザでYouTubeを開きます。縦画面では動画プレーヤーだけを自動監視し、全画面にも対応します。
5. 横長の字幕は最初の2〜3フレーム、短い字幕は同じ画面アンカーで次の文章が2フレーム続くことを確認して字幕帯を学習します。

「画面共有中の自動消灯を防ぐ」は既定でオンです。共有中の画面タイムアウトを防ぎ、読み上げ停止時に解除します。明るさはブラウザ・端末設定にも依存します。ロックボタンを無効化する機能ではありません。Android 15 QPR1以降では端末のロックによりMediaProjectionが終了するため、解除後にもう一度「画面共有を開始」が必要です。完全消灯中のOCR継続には対応しません。[Android公式仕様](https://developer.android.com/media/grow/media-projection#status_bar_chip_auto_stop)

別の文字を選び続ける動画では、通知の「手動で範囲指定」から字幕を囲んでください。

## 完全読み上げ

1. アプリの「ブラウザ自動停止の権限を設定」を押します。
2. Android設定で「焼き付け字幕リーダー」の通知へのアクセスを許可します。
3. 読み上げモードを「完全読み上げ」にします。

この権限はAndroidがブラウザのMediaSessionを取得するために必要です。本アプリは通知本文を読み取りません。ブラウザがMediaSessionを公開していない場合は停止できず、読み上げだけを続行します。

## ビルド

JDK 17、Android SDK 36、Gradle 8.13を使用します。

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

生成物は `app/build/outputs/apk/debug/app-debug.apk` です。GitHub Actionsの `Build Android APK` でもテストとAPK生成を行います。

## 現時点の制約

- 自動検出は時間変化を学習するため、動画冒頭の最初の字幕を読み逃すことがあります。
- 字幕と別の動画内文字が同じ画面アンカー・文字サイズ・更新周期で変化する場合、完全分離はできません。
- 場面転換の直後は字幕帯を再学習するため、最初の短い字幕を読み逃す場合があります。
- 自動学習の最初に短い字幕だけが1回表示された場合、その字幕は読み飛ばすことがあります。
- 同時追跡は最大2本です。3か所以上で会話字幕が同時更新される構成は優先度の高い2本だけを扱います。
- 近接した日本語2〜3行は1本として扱います。離れた字幕・サイズの違う字幕は結合しませんが、字幕と物体文字が近接する場合の誤結合は残る可能性があります。
- OCRが一度も認識できなかった行は復元できません。行欠落への対策は、同じ候補の安定待ち中に実際に認識した全文だけを使用します。
- 縦画面で動画プレーヤーが画面下半分に移動する特殊なレイアウトには未対応です。
- 画面点灯維持を有効にすると電池消費と発熱が増えます。端末を手動ロックするとAndroid 15 QPR1以降では画面共有が終了します。
- DRMや `FLAG_SECURE` で保護された画面は取得できない場合があります。
- 完全読み上げの停止・再開可否はブラウザのMediaSession実装に依存します。
- 縦書き、翻訳、クラウドOCRは対象外です。
