# 動画内字幕リーダー / In-Video Caption Reader

**v0.3.23 安定版**。Androidのアプリ一覧で見分けやすい、動画・字幕・音声の新しいアイコンを採用しました。

YouTubeのURLを入力するか、ブラウザからURLを共有すると、アプリ内で動画を再生しながら動画に描かれた日本語字幕をOCRして読み上げます。画面共有の開始操作は不要です。OCRと音声合成は端末内で実行します。動画の再生にはYouTubeへの通信が必要です。

## 使い方

1. アプリを開き、YouTube動画のURLを入力して「動画を開いて読み上げる」を押します。ブラウザの共有メニューからこのアプリを選ぶこともできます。
2. アプリ内の動画をタップして再生します。再生できる動画では字幕を検出して日本語音声で読み上げます。
3. 「読み上げ設定」で速度、声の音量、字幕の安定待ち時間などを調整します。再生画面の設定パネルからも変更できます。

再生画面の「読み上げを一時停止」では、動画を再生したままOCRと音声を止めます。「読み上げを再開」で現在表示中の字幕から検出を再開します。「設定」は動画を流したままパネルを開き、次の読み上げから速度・音量の変更を反映します。「トップ画面に戻る」はプレーヤーを閉じます。YouTubeの表示字幕（CC）は設定から切り替えます。

音量は0〜400%相当の一つのスライダーです。100%を超えると声の音声セッションだけに増幅効果をかけ、動画の音量は変えません。端末やTTSエンジンが増幅効果に対応しない場合は通常音量へ戻ります。旧版の音量とブースト設定は更新時に統合されます。

## 制約

- YouTubeがアプリ内での再生を許可しない動画では再生・OCRはできません。
- OCRは動画フレームに表示された文字を認識します。字幕と背景の文字の誤判定や読み飛ばしが起こる場合があります。
- 全画面再生および字幕表示（CC）を隠す機能は機種とWebViewの挙動に依存します。
- 端末の画面を手動でロックすると動画とOCRは継続できません。

以前の画面共有方式は [`legacy-screen-capture-v0.3.3`](https://github.com/eltnegcellist/burned-caption-reader-android/tree/legacy-screen-capture-v0.3.3) ブランチに保存しています。アプリの識別子は更新可能性を維持するため変えていません。

## ビルド

JDK 17、Android SDK 36、Gradle 8.13を使用します。

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

生成物は `app/build/outputs/apk/debug/app-debug.apk` です。GitHub ActionsでもテストとAPKを生成します。
