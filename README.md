# 焼き付け字幕リーダー Android v0.2.0

ブラウザで再生中のYouTube画面をMediaProjectionで取得し、ML Kit日本語OCRとAndroid標準TTSだけで、映像へ焼き付けられた字幕を読み上げます。動画・画像・認識結果は端末外へ送りません。

## v0.2.0の主な変更

- ML Kitの行座標を利用した字幕帯の自動検出（既定）
- 字幕位置・中央寄せ・文字サイズ・時間変化を組み合わせ、ロゴやブラウザUIを抑制
- 手動ROIは自動検出が合わない動画の補助機能として維持
- OCRが一時的に空になっても直前字幕を忘れず、類似字幕を60秒間重複除去
- 「追従バランス」では現在の文を最後まで読み、待機中は最新字幕1件だけを保持
- 待ち時間に応じて読み上げ速度を最大45%自動加速
- 通知アクセスを許可した場合、対応ブラウザのMediaSessionを停止・再開する「完全読み上げ」

## 対応範囲

- Android 8.0以上（Galaxy S25 / Android 16を主対象）
- Chrome、Samsung Internetなどで表示する日本語横書き字幕
- 自動字幕帯 / 手動字幕領域
- 追従バランス / 最新字幕優先 / 完全読み上げ
- 約2〜3fpsのローカルOCR

## 推奨の使い方

1. 検出範囲を「自動検出（推奨）」にします。
2. 読み上げを「追従バランス」にします。
3. 「画面共有を開始」を押し、Androidの確認画面で許可します。
4. ブラウザでYouTubeを開き、できれば動画を全画面表示します。
5. 最初の2〜3フレームで字幕位置を学習し、新しい字幕から読み上げます。

別の文字を選び続ける動画では、通知の「手動で範囲指定」から字幕を囲んでください。

## 完全読み上げ

1. アプリの「ブラウザ自動停止の権限を設定」を押します。
2. Android設定で「焼き付け字幕リーダー」の通知へのアクセスを許可します。
3. 読み上げモードを「完全読み上げ」にします。

この権限はAndroidがブラウザのMediaSessionを取得するために必要です。本アプリは通知本文を読み取りません。ブラウザがMediaSessionを公開していない場合は停止できず、読み上げだけを続行します。

## ビルド

JDK 17、Android SDK 36、Gradle 8.13を使用します。

```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```

生成物は `app/build/outputs/apk/debug/app-debug.apk` です。GitHub Actionsの `Build Android APK` でもテストとAPK生成を行います。

## 現時点の制約

- 自動検出は時間変化を学習するため、動画冒頭の最初の字幕を読み逃すことがあります。
- 字幕と別の動画内文字が同じ位置・同じ大きさで同時に変化する場合、完全分離はできません。
- 全画面表示の方がブラウザUIの誤検出が少なくなります。
- DRMや `FLAG_SECURE` で保護された画面は取得できない場合があります。
- 完全読み上げの停止・再開可否はブラウザのMediaSession実装に依存します。
- 縦書き、翻訳、クラウドOCRは対象外です。
