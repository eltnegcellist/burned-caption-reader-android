# OCR方式を選べる実機検証APK（1.0.3-preview）

Android 8.0以降向け。ARM64版は約72.6MB、汎用版は約204.8MBです。通常の64bit Android端末ではARM64版を使用できます。汎用版はARM64、ARM32、x86、x86_64を含みます。

## 使い方

1. APKを端末に転送してインストールします。
2. アプリの「読み上げ設定」→「字幕の読み取り方式」を開きます。
3. 次の3方式から選びます。

| 設定 | 動作 |
|---|---|
| ML Kitのみ | 文字検出と読み直しの両方にML Kitを使用 |
| 現行：PP-OCR文字認識併用 | 文字位置はML Kit、選択された字幕の読み直しにPP-OCRを使用 |
| 改良版：PP-OCR検出併用（実験） | 現行方式にPP-OCR検出と、見落とし行の追加・既存行の修正を追加 |

初期値は現行方式です。設定は保存されます。動画再生中の設定パネルでも変更できます。処理中の画像が終わってから切り替え、モデルと字幕追跡・重複防止の状態をリセットします。動画の再読み込みは不要です。比較するときは同じ動画の同じ場面を使用してください。

改良版には字幕以外の文字の混入と、一部動画での処理時間増加が既知の課題として残っています。新しい方式が全面的に優れているという判断はしていません。PP-OCRの2方式はML Kitと併用する構成で、完全なPP-OCR単独方式ではありません。

モデルはAPKに同梱しています。診断記録をオンにした場合は、方式の変更イベントと動画画像・処理完了イベントにocr_modeを記録します。既存のprocessing_msで処理時間を比較できます。診断記録は初期状態でオンにしていません。

## 確認済み

231件の単体テスト、Androidエミュレーター上で3方式の実際のOCR推論、設定UIからの保存と画面再作成後の復元、プレーヤーの方式選択、処理中の切替保留、旧モデルの終了を確認しました。最後のARM64 APKのコード・モデル・ARM64ネイティブライブラリは、この動作確認を行った汎用版とバイト単位で一致しています。設定メニューの3項目の表示も画像で確認しました。

これは動作確認であり、実機の音声・遅延・精度は未検証です。以前の約5分×4動画の精度検証で使った検出・認識アルゴリズムとパラメータを、今回の選択機能のために変更していません。署名は以前このMacで作った検証APKと同じ証明書です。このAPKは実機比較向けのプレリリースです。

## 処理時間の参考値

Android API36 ARM64エミュレーターでの1画像処理時間です。実機の速度や音声の遅れではありません。

ML Kitのみの過去のプロマネコ検証（2026-10-07）は中央値524ms。同じ検証でPP認識併用は984msでした。その検証は採点30枚と直前30枚を入力し、今回の全履歴入力とは異なります。3方式を同じ画像履歴で比較した測定はまだありません。

2026-10-10の約5分×4動画、計1261枚の実画像履歴では次の結果でした。処理時間には字幕検出・領域の選択・再認識を含みます。

| QuizKnock | 42ms | 202ms | 382ms | 732ms |

| 東海オンエア | 14ms | 102ms | 116ms | 238ms |

映像の文字量・選択領域数・字幕のない場面の割合と、実行時のMac負荷に左右されます。別投稿者の比較前にAVDを再起動しています。①の過去値と②③の最新値を直接比べて速度順位を決めることはできません。
